# Myengine - Custom Ray-Casting Engine

A lightweight ray-casting engine written in C++ from scratch

# Features 
-  Real-time ray-casting renderer
-  Texture mapping and shading
-  Cross-platform suppor
-  Optimized for performance (~60 FPS on modern hardware)

# Tech Stack
- Launguage: C++17
